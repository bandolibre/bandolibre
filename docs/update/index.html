About the update

How it works

The instrument restarts into its firmware update mode, where it shows up as the MIDI device "Bandolibre firmware update". This page writes the new firmware page by page, checks each page, then checks the whole image before making it bootable. The instrument then restarts with it. Your saved settings are kept.

If something goes wrong

Closing this page, losing the cable or the power during an update is safe: the instrument comes back in firmware update mode instead of starting a half-written firmware. Open this page again and choose Resume update.

Without a browser that supports Web MIDI, hold the leftmost function button (FN2) while plugging the instrument in: a drive called BANDOLIBRE appears. Copy the .uf2 file onto it.

Other pages

The configuration tool and BandoPM can stay open: they leave the instrument alone during the update and reconnect afterwards.
