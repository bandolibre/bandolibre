# 3D-printed keys

The keys are printed one at a time (PrusaSlicer's *Complete individual
objects*). `arrange_3mf.py` packs them as close together as possible while
still letting each key be printed to completion on its own.

The other parts are in the
[Onshape model](https://cad.onshape.com/documents/313e70e978bf056a8dd7d76c/v/5c5fbc4088ac379c1bd1b53a/e/c6a89cb028bdc195ff70596f).
