# Update the main board software

- Download the latest `main-g474.uf2` from the https://github.com/bandolibre/bandolibre/releases
- Keep the left-most button pressed while plugging the Bandolibre USB to a
  computer.
- The Bandolibre should be detected as new storage device.
- Drop the file `main-g474.uf2` to this storage.
- Upon sucessfull update drive should disaper and the Bandolibre software is now
  up to date.
